# 用户价值对照记录

现已提供可运行的本地主持工具，包含两套原创邮件、同一结果编辑器、服务端计时、12项自动核对、主持人复核和匿名 JSON 导出。

**完整方法与截图：**[用户价值对照图文报告](../competition-value-2026-11-04/README.md)。材料和逐例真实模型预检在报告中可直接下载。

## 开始采集

```sh
npm run study -- --practice
```

打开 `http://127.0.0.1:3190` 熟悉流程。真实参与使用：

```sh
npm run study -- --live --settings <private-file> --max-calls 20
```

每位参与者完成两轮，编号按 P01、P02、P03、P04 轮换人工/Daylight 与 A/B 材料顺序。点击开始到确认完成持续计时，包括阅读、模型等待、核验与修正。两轮完成后统一展示评分，再由主持人核对标题含义和冲突说明。

## 记录与汇总

结果保存在每次新建的 `work/value-study-*`。真人配对汇总纳入完成两轮、同意匿名记录且标为目标用户参与的真实模型记录，练习、自查、中断记录另列。主持人导出 JSON 后，按 [CSV 字段](value-study.csv) 整理提交材料。

探索性验证计划采集 3–5 位目标用户，保留逐人耗时、范围、中位数、错误、帮助与反馈；当前真人记录等待采集。10次真实模型的自动材料预检已完成，两套均12/12，原始usage及延迟见完整报告。
