# 三分钟演示讲稿

主入口：<https://daylight.yunforis.com/experience>。电脑直接打开，手机扫码打开同一入口。公开体验的输入为原创合成邮件、提取为预置结果，日历和任务由生产工具当场计算。真实模型回归另在技术页和证据包展示。

备用：[三分钟字幕讲解视频](https://daylight.yunforis.com/competition/demo.mp4)，采用实际页面截图和工程图片，1920×1080，无音轨；12 个镜头和字幕见 [清单](evidence/video-manifest.json)。

## 现场准备

1. 确认正式 HTTPS、二维码和手机网络可打开；从未登录的新窗口开始。
2. 用 390px 与桌面窗口各走一次七步。微信检查正常浏览、折叠原文、工具记录、返回与重试；校园定位与地图外跳另行操作。
3. 技术页保留实际环境与原始记录的链接。若网络临时受限，使用本轮截图讲解视频与本地 `npm run demo -- --no-build`。
4. 真实邮箱展示由本人登录操作，避开私人正文；主动发信按已授权收件范围执行。

## 五项追问定位

- 场景：日程、材料、来源和后续变更如何连起来？看步骤 1、3、7。
- 架构：谁保存任务状态，消息丢失怎么办？看架构图、租约及幂等记录。
- Agent：模型错了会发生什么？看整封校验失败、修正重试及模糊目标测试。
- 工程：如何复现与回滚？看 Compose、发布 manifest、备份与镜像记录。
- 成本：测量包含哪些环节？分别展示公开样例工具、合成邮件真实模型、真实邮箱同步三种口径。
