# Daylight 技术报告配图 · image-2 生成提示词

对应文档：`docs/hackathon-report/daylight-report.tex`（`\figph{...}` 占位图 F1–F25）。
每条提示词都可**单独粘贴**给 image-2 使用（已含统一风格句）。

## 0. 通用约定

**统一风格句**（每条提示词开头已包含，请勿删除）：

> 扁平化矢量信息图（flat vector infographic），2D 正视，圆角矩形卡片 + 细线描边（1.5px），无照片、无 3D、无重阴影、无渐变眩光，配色严格：深墨蓝 `#142D4E`、中蓝 `#294F78`、灰蓝 `#61747B`、浅底 `#F0F4F8`、浅青灰线 `#D7E3E1`、琥珀金 `#F4B544`（金色只用于「当前步骤/强调/告警」，总面积 <10%），无衬线字体、字重中等，留白充足，网格对齐，商业技术报告插图风格；除指定标签外不要添加任何文字。

**图内文字规范（很重要）**

- 只允许出现提示词里用引号给出的**短英文/数字/缩写标签**；术语本身就常用英文（API、Worker、PostgreSQL、IMAP、SMTP、draft、confirmed），比生成中文更可靠。
- 不要在图里生成中文句子或长句：图像模型写中文字容易出错，中文说明放在 LaTeX 图注（`\caption`）里。
- 如果某一版必须用小字标注，请控制在每处 ≤3 个词，字号足够大。

**负面提示（可放在 prompt 末尾或 negative prompt 栏）**

> no photograph, no 3D render, no isometric, no heavy drop shadow, no glossy gradient, no neon, no texture noise, no watermark, no misspelled text, no extra paragraphs of small text, no distorted logos, no cluttered background.

**整体一致性检查（生成 25 张后统一核对）**

1. 同一套六色配色，金色占比始终 <10%；
2. 卡片圆角、线宽、箭头形状、图标风格一致；
3. 每张图都有清晰的「数据方向」（箭头）与「信任/边界」（虚线框或切分线）；
4. 每张图右下角留一小块浅底区域，用于后期在 LaTeX 里叠「证据来源」小字。

**建议尺寸**：报告页宽约 164 mm、图高 42–62 mm（横幅比例约 3:1）。因此**优先生成横构图**，推荐 16:9（1600×900）或更宽 21:9（1920×820）；不要生成竖向或方形图。
