## 通过真实邮件测试

建议每封邮件只附一份 PDF，主题如 `求职投递｜赵明轩｜资深后端开发工程师`，正文只写“您好，附件为我的求职简历，请查收。”。只发送 PDF，不必附本说明。

使用 HR 场景账号同步收信邮箱，核对人才库中个人信息、求职意向、教育、工作、项目、技能和语言等字段。07 的第 2 页还包含科研、技术报告、受理中专利和荣誉；技术报告没有外部发表记录，专利尚未授权。学校所在地与现居城市应分别保存，英文简历没有提供年龄或生日。

这些 PDF 均为文字版，不用于检查无文字层扫描 OCR；扫描样本可使用上一批 `docs/resume-test/` 中的 09、10。若后续测试真实面试邀请，请在待审核草稿中将收件人改为自己控制的测试邮箱。
