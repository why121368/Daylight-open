## 设计与兼容策略

统一场景模板定义字段、阶段、视图、识别规则、材料、能力权限和验证样例；模板版本固定在工作台实例中。工作台属于登录用户，绑定该用户拥有的邮箱；事项、行动、材料版本及来源证据独立记录。阶段、任务执行状态与材料状态不能混用。

首期内置模板：保研，申博/海外研究项目/RA，校招求职，科研投稿/会议，智能招聘；后增发票助手。页面分类上智能招聘与发票助手为官方模板，其余四项为社区模板，闭环能力不变。招聘采用现有引擎适配，不重写或复制 OCR、候选人、邀约等能力。原邮箱数据引用保留，通过兼容工作台承接。`/app/recruitment` 与 `/app/invoices` 按合并约定保留直达路由。

模板导出采用字段白名单，不能带出实例数据和凭据。外部动作必须调用已有权限/确认机制，跨工作台引用不重复执行副作用。外部官网、报名系统、群聊等支持手工来源与回执，不自动假定完成。海外时间保留原始 IANA 时区与 UTC，处理夏令时歧义。
