# 校园生活：定位导航、邮箱安排、周菜单与小 D

日期：2026-11-02，北京时间。此文记录本次功能与开发阶段验证；随后已发布公网，详见[手机与公网更新](campus-mobile-public-2026-11-02.md)。微信定位与实际行走尚未真机验收。

## 1. 地面定位与步行导航

1. 手机扫码打开站点的 HTTPS `/campus`，点击地图右侧定位按钮，并允许微信及系统位置权限。
2. 定位成功后显示位置和精度范围。选择终点、点击「规划路线」，有效定位优先作为起点；也可以手动选起点。
3. 点击「打开腾讯步行导航」，在腾讯地图继续规划与实时引导。未定位时可以只传终点，由腾讯请求定位。点击外部导航会把所选起终点发给腾讯；默认校园分享链接不包含 GPS。
4. 微信拒绝定位或无法获取时，检查系统位置权限，或用微信右上角菜单在系统浏览器打开。同一站点在普通 HTTP 的局域网地址下通常无法使用浏览器定位；localhost 例外不能证明手机可用。

浏览器 GPS 和本站目录使用 WGS84，腾讯和高德导航请求转换为 GCJ-02，高德返回的路线转回 WGS84。定位超过 60 秒或精度大于 100 米时不能用于新的站内规划；连续更新只在有效 GPS 路线下按时间和位移节流重规划。关闭定位会清除用于后续请求的位置。

站内先使用已维护的地面路网。无可用路网且 API 进程配置 `DAYLIGHT_AMAP_WALKING_KEY` 时，调用高德步行 Web Service 返回道路折线和步骤；此 Key 只在服务端使用。Compose 在私有 env 文件设置此变量后重建 API；直接运行 Node 则在进程环境设置。该服务的权限、额度、计费和可达性由运维自行核验。本轮高德响应使用合成接口验证，尚未以真实 Key 实连。

未配置地图 Key 时生成腾讯步行导航入口，不伪造路线、距离或耗时。地图服务失败时显示错误，腾讯入口仍可用。第三方路网可能缺少校内小路，建筑中心也不一定是入口；暂不承诺避雨、无障碍或临时封闭识别。主页面仅提供地面步行，原地下几何维护与相关底层数据保留兼容。腾讯页面在微信中的实际跳转与校园道路精度需真机核验。

## 2. 本人上科大邮箱安排

在工作区「设置」绑定 `@shanghaitech.edu.cn` 或其子域邮箱并完成 IMAP 与模型配置。已有后台邮件同步继续读取邮箱、使用本人模型提取日程和活动；校园页面不再重复调用模型提取同一封邮件。

「日程」自动合并本人上科大邮箱的有效邮件日程；「活动」的「上科大邮箱 · 自动同步」区域按当前时间、查询和地点筛选展示。进入页面、窗口重新聚焦及每分钟刷新会读取更新。也可点击「立即同步邮件」调用原同步流程；生产环境持久排队，按钮返回不代表处理完成。

这些记录是原邮箱日历的实时投影：原记录取消、改期、删除或婉拒会反映到校园页，不建立一份脱离原记录的副本。不同邮箱同 ID 使用隔离的来源编号。手动、演示及校园反向导入记录不参与邮件投影。地点只有在明确匹配时才关联地图，否则保留原地点文字；全天结束仍为最后一天次日零点。

校园公开目录、游客、小 D 游客查询及其他账号无法读取这些私人记录。不会自动把私人邮件发布到公共活动目录。公开发布仍使用原有管理员审核流程。邮箱配置保存不代表 IMAP 实连，提取成功率、失败重试和扫描范围沿用原邮箱设置；未扫描或提取失败的信息不会凭空出现。

## 4. 校园小 D

校园各标签页右下角「小 D 助手」支持：

- 「从南门到图书馆怎么走」：解析起终点，地点重名时给出选择，生成地面导航卡。
- 「我最近在控糖，今天中午 15 元以内可以吃什么」：先按日期、餐次、预算、售罄和停业筛选，再从同一食堂搭配菜品，显示窗口、价格和菜单原图。
- 「这周有哪些活动」「今天有什么安排」：查询公开活动和本人可见的日程，显示时间与地点，可继续导航。

2026-11-03 增强已发布公网（[发布记录](campus-assistant-public-2026-11-03.md)）：游客无需模型配置可使用基础查询。登录且模型已配置时，默认向本人模型发送当前问题和最近最多六条对话（含回答卡片摘要），可能产生费用。模型通过现有 JSON 接口返回最多四步只读工具计划，服务端校验工具白名单、日期、时长、预算及前序引用后，从实际目录和本人权限范围内执行；不使用模型编造的结果。未配置时明确提示基础查询；已配置模型调用失败时显示错误，不静默改成规则结果。HTTP `useModel:false` 保留显式基础查询兼容。

点击「能做什么」显示「从一句话开始」，六个场景先填入输入框供修改：预算控糖晚餐、明日日程与地点、下一项安排导航、至少60分钟的自习空档、不冲突的讲座、避雨步行路线。模型可调用 `weekly_menu`、`personal_calendar`、`campus_events`、`search_places`、`find_free_time`、`recommend_events`、`ground_navigation` 和 `help`。日程查询结果能作为下一步导航目的地；多个结果或地点缺失时要求补充。空档合并本人课表、安排和学校邮箱日程中的重叠时段，全天安排也占用时间；活动建议只做时间冲突检查，未计入路程。每次回答提供可展开的处理依据。该增强的验证及发布状态见 [STATUS](../STATUS.md)，以下11月2日记录保留为历史验证。

控糖建议依据菜名筛选，没有实测营养和加糖量；菜品合计不包含主食。过敏、严格素食等缺少完整配料依据时，不保证菜品安全，提示向窗口确认。本轮没有新增发信或对外报名动作。
