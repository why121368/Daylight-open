## 工程验证与当前边界

- `node --test --test-concurrency=2 server/*.test.js`：**393/393 通过**，约 65.8 秒，隔离数据目录；包含新增 2 项工作台前置业务回归、已有 HTTP 回归增强及 6 项评分器/脱敏/隔离验证。外部依赖由测试夹具控制，本地回归数量不是模型质量分数。
- `npm run build`：通过，约 17.65 秒；仍有已有的大包提示（主 JS 约 1.83 MB，gzip 约 548 kB）。本轮不将前端加载性能写成已优化。
- 工作台前置修复：仅 `prepared`、已取消或缺失前置不会放行；事务内再核查防止排队期间失效。当前仍按通用 `submitted / sent / confirmed` 人工回执契约放行，尚未按每个依赖指定必要回执类型，也未自动核验外部事实。
- 本轮没有新增浏览器实点、真实 IMAP/SMTP、云资源部署、数据库故障注入或多副本验收。15 条固定输入均较短、无真实用户抽样且每例只调用一次，不能推定总体准确率、重复稳定性或所有复杂邮件效果。
- 下一批优先增加自然长邮件、多封连续通知、作废后新要求、冲突、附件与用户纠错；固定下一版数据集并保留失败，不覆盖本次原始结果。
