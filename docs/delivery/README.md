更新日期：2026-11-04（北京时间）。本目录为源码与隔离演示的启动入口。[最新交付包与逐文件校验](../competition-delivery-2026-11-04/README.md)保存本轮设计及复现过程；[公网技术与实测](https://daylight.yunforis.com/evidence)提供线上功能和测量记录。

## 立即运行 Demo

需要 **Node.js ≥22.19、npm**。在项目根目录执行：

```sh
npm ci
npm run demo
```

打开 **http://127.0.0.1:3180/experience**，免登录完成七步体验。继续访问 `/evidence` 查看技术与实测，`/demo` 查看分章讲解；完整工作区在 `/login`，点击 **进入演示工作区**。已有依赖时可直接运行第二条命令。端口冲突时使用 `npm run demo -- --port 3181`。Ctrl+C 结束本次演示。

| 账号 | 用户名 | 口令 | 用途 |
| --- | --- | --- | --- |
| 演示用户 | `demo` | `DaylightDemo2026!` | 邮件、日历、待办、招聘、发票和工作台 |
| 演示管理员 | `demo_admin` | `DaylightDemo2026!` | 管理后台与校园目录维护 |

这两组是公开的合成凭据，仅由隔离启动器在新目录中创建。演示只监听回环地址，每次生成 `work/demo-*/data`，不会使用已有用户的 `data/`。退出后保留演示材料；再次运行会创建新的样例，无需清空任何原有数据。

## 可直接展示的内容

- 七步体验：创建、冲突、改期、重复、异常、重试、取消；地址直达当前步骤，支持刷新和返回恢复。
- 技术与实测页面、三分钟分章视频及同步讲稿。
- 邮件转日程；后续取消与改期保留原安排及新旧关联；重复导入保持幂等。
- 冲突邮件、候选时间和回复草稿；示例回复保留在本地。
- 邮件标签、待办合并、日历手动编辑与执行记录回放。
- 三位原创招聘候选人及可预览的 PDF 简历。
- 一张原创票据样本、原件预览和逐字段核对；金额保持十进制字符串。
- 邮箱知识库的关键词检索与来源引用。
- 招聘、发票、科大学习站和邮件收发工作台；科大学习站的学校登录和真实课件采集需要用户另行配置。
- `/campus` 公开校园地图、路线、活动、餐饮、社区与个人计划；地图、菜单等初始目录为示意资料。

演示进程屏蔽外网请求，不连接真实邮箱、不调用付费模型或 SMTP。小 D 的真实模型对话、OCR、向量化和真实服务联调分别使用正式配置并按授权验证，演示不伪装这些调用成功。关键词检索直接返回已入库片段。

## 验证、打包与部署

```sh
# 完整离线交付检查：回归、构建、评测语料、Demo HTTP 与部署资产
npm run verify

# 单独演示自检；检查结束后停止自己的进程
npm run demo:check

# 部署资产预检，不启动容器
npm run deploy:check

# 通过当前源码验证后，生成源码 + dist + 本轮证据的 tar.gz 与 SHA-256
npm run release:bundle
```

`npm run verify` 的报告在 `work/release-check-*/summary.json`，Demo 在 `work/demo-*/verification.json`。有条件跳过的依赖测试不会记为实连成功。测试及演示子进程移除继承的服务凭据，并预加载 I/O guard，阻止访问仓库原 `data/` 和外网。

交付包输出到 `output/delivery/`，包含逐文件 SHA-256、来源提交、源码与构建摘要及工作区修改标记。打包器比较当前内容和五阶段验证结果，先逐文件核对暂存目录，再创建压缩包。`START-HERE.md` 为解压后的启动入口，也进入清单。首次 `npm ci` 联网安装依赖；包内用户数据由演示启动器创建。

解压后的检查命令无需安装 npm 依赖：

```sh
node scripts/verify-delivery.mjs . --out work/package-integrity.json
```

检查缺失、改写、额外文件、源码与构建摘要、五阶段及日志对应关系。`node_modules`、`work`、`data`、`output` 为安装运行目录，回执可保存在 `work/`。已有依赖时也可使用 `npm run release:check -- .`。
