所有受影响提交的 SHA 会变化，历史发布记录中的旧 SHA、旧文件摘要、包大小及截图只描述当时的私有版本，不再用于验证当前开源源码或重新生成的截图。应基于新提交重新打包和生成校验清单，不能把修改后的历史证据当作原始文件摘要仍有效。

协作者请重新克隆；需要保留旧本地工作时先私下备份，再迁移必要改动，避免把旧提交或含隐私资料的包重新推回。公开前建议重置旧演示账号口令；本次仓库审计没有修改线上账号或服务配置。GitHub 可能保留旧提交缓存和既有下载包；本轮当前可列出的 Actions 附件已检查，无 Release。发现旧提交入口仍可访问隐私内容时，应联系 GitHub Support 清理缓存；已有私人下载副本应自行保密或重新生成。仓库可见性由所有者手动切换。
